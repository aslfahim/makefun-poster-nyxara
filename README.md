NYXARA — a travel poster for a city that lives in a crater, under a ringed
planet that never sets. One Node program paints it from raw pixels: a deep
violet night, a banded ringed planet, a small cratered moon, terraced crater
streets scattered with warm and cool windows, and a crystal spire at the
city's heart catching the planetlight. The city's name is set in hand-drawn
stroke letters low on the crater floor. It writes one PNG to
/output/entry.png.

## Run it

```sh
node main.ts
```
